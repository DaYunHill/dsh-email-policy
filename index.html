dsh-email

A personal mail client for a DSH desktop agent · 个人邮件客户端

What it is · 这是什么

dsh-email is a local, single-user email integration that lets its owner read and send mail from their own Gmail account inside a private desktop agent. It is not a public service and has no other users.

它是一个本地运行、仅供本人使用的邮件集成：在自己的私人桌面助手里收发自己的 Gmail 邮件。 它不是对外提供的服务，也没有其他用户。

Data · 数据处理

All data stays on the owner's machine. OAuth tokens are stored in a local file; nothing is sent to a third-party server. The only network destinations are Google's own APIs.

所有数据都留在本人电脑上。OAuth 令牌存放在本地文件里，不会发往任何第三方服务器； 唯一的网络目的地是 Google 自己的接口。

Scopes · 申请权限

Only https://mail.google.com/ is requested, and only to read the owner's inbox and send mail on their behalf.
